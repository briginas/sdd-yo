# Notifications

## Purpose <!-- sdd:purpose -->

Define delivery behavior.

<a id="req-a1000001"></a>

## REQ-A1000001 — Deliver notifications

```sdd
kind: behavior
verification: automated
```

### Statement <!-- sdd:statement -->

The system shall deliver each notification once.

### Acceptance criteria <!-- sdd:acceptance -->

- A delivered notification is recorded.

### Rationale <!-- sdd:rationale -->

Recorded delivery supports operator review.
